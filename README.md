# COINT Launcher Android

Android-лаунчер COINT на основе [Amethyst 1.1.7](https://github.com/AngelAuraMC/Amethyst-Android/tree/1.1.7), коммит `56194e3d317a407c452dfc243722877bf552cf83`.
Исходная история и LGPL-3.0 сохранены. Проект находится на раннем этапе разработки и не является официальным продуктом AngelAuraMC.

## Возможности

- Интерфейс COINT и собственный значок. Debug-версия с package ID `ru.coint.launcher.debug` устанавливается рядом с Amethyst.
- Импорт локального `.mrpack` с автоматическим выбором импортированного профиля.
- Поддержка полного профиля GTNH из LWJGL3ify 3.x без запуска старого графического установщика Forge.
- Настройка Android-профиля при импорте: MobileGlues, отключение shared GL contexts, Linux desktop entry и загрузочных splash-экранов.
- Начальный размер Java heap — 3072 МиБ для устройств с RAM от 6 ГБ. Сохранённое значение не перезаписывается.
- Вход в собственный аккаунт COINT через GravitLauncher API: сохранение сессии, восстановление и обновление токенов. Пароль не сохраняется; токены шифруются Android Keystore и исключены из резервных копий Android.
- Русскоязычный интерфейс COINT с английским переводом. Стандартный вход Minecraft/Microsoft сохранён отдельно.

Сборки импортируются отдельно и не входят в APK или репозиторий.

## Сборка на Windows

Требуются JDK 17, Android SDK Platform 34 и Build Tools 34.0.0. Минимальная версия Android — 10 (API 29), поддерживаемые ABI — ARM64 и x86_64.

Откройте корень репозитория в Android Studio. Путь к SDK хранится в локальном файле `local.properties`, исключённом из Git.

Для сборки с готовыми нативными библиотеками официального Amethyst 1.1.7:

```powershell
./scripts/Prepare-Engine.ps1
./gradlew.bat :app_pojavlauncher:assembleDebug :app_pojavlauncher:testDebugUnitTest -PcointPrebuiltEngine=true
```

Скрипт проверяет SHA-256 исходного APK и извлекает нативные библиотеки и runtime assets в игнорируемый каталог `.vendor/`. Java-код и ресурсы приложения компилируются из исходников этого репозитория. Режим привязан к движку версии 1.1.7; обновление движка требует соответствующих артефактов.

Для полной сборки движка из исходников инициализируйте Git submodules, установите указанную в Gradle версию NDK и запускайте сборку без `cointPrebuiltEngine`. Дополнительные инструкции и лицензии зависимостей: [README-UPSTREAM.md](README-UPSTREAM.md) и [LICENSE](LICENSE).

Debug-сборка использует тестовую подпись. Для выпуска COINT требуется собственный ключ подписи, хранящийся вне репозитория.

## Совместимость и тестирование

На Android 17 x86_64 проверены главный экран COINT, начальное выделение памяти и импорт тестовых пакетов: создание и выбор профиля LWJGL3ify, MobileGlues и изменение настроек конфигурации. Unit-тесты проверяют правки конфигов, защиту ZIP-импорта, сообщения протокола авторизации, выбор способа входа, ошибки и обновление сессии.

На эмуляторе также проверены русская и английская локализации экрана COINT, очистка пароля при пересоздании экрана, шифрование и целостность хранилища сессии, удаление локальной сессии и анонимное подключение к GravitLauncher API. Успешная авторизация реальным аккаунтом COINT пока не проверена.

Полный GTNH с 331 модом запущен до главного меню в исходном Amethyst: эмулятор с 8 ГБ RAM, Java 25.0.5, heap 3072 МиБ, MobileGlues. Полная сборка GTNH в APK COINT, ARM-устройства, игровой мир и подключение к серверу пока не проверены.

Нативные библиотеки Amethyst 1.1.7 требуют системного режима совместимости на устройствах со страницами памяти 16 КБ.

## Интеграция GravitLauncher

Интеграция находится в разработке. Ориентир совместимости — настольный клиент GravitLauncher `5.7.9-1 stable`; совместимость с LaunchServer требует отдельной проверки.

Вход COINT доступен на главном экране и в выборе способа авторизации. После перезапуска откройте «Аккаунт COINT» и нажмите «Восстановить сессию». Кнопка выхода удаляет локальную сессию; серверный отзыв сессии пока не реализован.

Игровая авторизация через authlib и загрузка сборок ещё не подключены. API-сессия COINT хранится отдельно от Minecraft/Microsoft и не используется в качестве игрового токена. Запуск игры с аккаунтом COINT пока недоступен.
